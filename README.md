# Pentti

A Forge app that measures what a factory does not know about its own machines, then helps close the dangerous gaps first. Built for Atlassian Codegeist 2026, category Apps for Specialized Industries.

## What is real and what is made up

- SCAN: the machine mix (models, firmware, device types, vulnerabilities) comes from an anonymized scanner export of a real manufacturing environment. Names, addresses and sites are remapped.
- GEN: the company (Tervaniemi Works), its plants, people, Confluence pages and Jira issues are generated for the demo. All fictional.
- SCORE: knowledge, risk and danger scores are computed by the app, with plain code and tests. The model does not do arithmetic.
