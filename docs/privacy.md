# Pentti - privacy policy

Last updated: 2026-11-04.

Pentti is a free Forge app for Jira and Confluence, built for Atlassian Codegeist 2026 by [fill: your name or company]. Contact: [fill: contact email].

## What Pentti stores

Pentti stores data only in Forge storage on Atlassian's infrastructure. It sends no data to servers outside Atlassian.

- When someone presses "I checked this" on a machine, Pentti stores that person's Atlassian account ID and the time. This is the only personal data Pentti stores.
- Setup data: the Jira project key and Confluence space key chosen on the admin page, the ids and keys of the pages and issues Pentti created, the install date, and the Teamwork Graph connection id.

## What Pentti writes to your site

- Demo Confluence pages and Jira issues, labelled `pentti-demo`.
- Jira tasks that a user asks Pentti to create. They are created as that user.
- One asset card per machine in the Teamwork Graph, when an admin connects the Pentti connector.

## Who sees the data

Nobody outside Atlassian receives data from Pentti. Rovo Chat conversations with the Ask Pentti agent are processed by Atlassian under Atlassian's own terms. If an admin enables Pentti's MCP tools and a user connects an AI client, that client receives the answers of the tools the user calls.

Pentti has no analytics and sets no cookies. It does not sell or share data.

## Deleting data

Reset on the Pentti admin page removes everything Pentti created on the site and the stored "I checked this" records. Uninstalling the app removes its Forge storage under Atlassian's rules for Forge apps.

## The demo data

The company Tervaniemi Works and its people are fictional. The machines come from an anonymized scanner export. No real person's data is in the dataset.
